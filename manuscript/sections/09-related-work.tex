\section{Related Work}
\label{sec:related}
\paragraph{Cache and dependency validation.} Version-based validation is established in HTTP~\cite{rfc9110}, collection synchronization~\cite{rfc6578}, NFS~\cite{rfc7530}, AFS callbacks~\cite{howard1988afs} and leases~\cite{gray1989leases,burrows2006chubby}. Coda, Bayou and session guarantees address disconnected reconciliation~\cite{kistler1992coda,terry1995bayou,terry1994session}; a mobile client asleep past the invalidation window drops its whole cache~\cite{barbara1994sleepers}. We apply optimistic validation~\cite{kung1981occ} to Android query, incarnation and lifecycle boundaries. Android providers expose neither the read snapshot of snapshot isolation~\cite{berenson1995critique,fekete2005making} nor the per-key causality of dotted version vectors~\cite{preguica2010dvv}. Input memoization follows build systems' content comparison~\cite{mokhov2018build}; Make decides rebuilds by modification time~\cite{feldman1979make}, which must only move forward~\cite{mokhov2018build}. Distributed stores trade read freshness for delay through lock-free reads in the past~\cite{corbett2012spanner}, probabilistic staleness bounds~\cite{bailis2012pbs} and the latency side of PACELC~\cite{abadi2012pacelc}; an Android reader has no timestamps or quorums to trade, so it refreshes or declines.

\paragraph{Mobile state and memory.} Android Contacts and Media\-Store expose version or generation evidence~\cite{android_syncadapter,android_mediastore}; iOS Contacts and Photos expose persistent change history~\cite{apple_cnchangehistory,apple_phpersistent}. MobileGPT stores screens and sub-tasks~\cite{lee2024mobilegpt}; MemGPT, Mem0, A-MEM and Zep organize persistent memories without certifying external provider queries~\cite{packer2023memgpt,chhikara2025mem0,xu2025amem,rasmussen2025zep}, and Zhang et al.\ compare mobile-agent memory architectures~\cite{zhang2026mobilememory}. Memory benchmarks for LLM agents test knowledge updates and temporal reasoning over conversations~\cite{wu2025longmemeval,maharana2024locomo}, where a stale memory is an answer error, and a preprint limits stale reuse in a semantic retrieval cache with per-tier error budgets~\cite{mansoor2026freshcache}; we ask whether external phone state changed. Tether tracks dependency support~\cite{wang2026tether}; our event-propagation ablation does not reproduce its complete system.

\paragraph{Lifecycle and actions.} Android process killing and background execution are well studied~\cite{lebeck2020marvin,liang2020acclaim,chen2015background,pathak2012nosleep}, including freezing in a large Xiaomi deployment~\cite{zheng2024mproc}. App-state testing studies pause, kill and restart data loss~\cite{shan2016krefinder,riganelli2020dataloss,adamsen2015adverse}; we examine another component's state changing during absence. AndroidWorld, LlamaTouch, AppAgent, Mobile-Agent and AutoDroid provide agent workloads~\cite{rawles2025androidworld,zhang2024llamatouch,zhang2025appagent,wang2024mobileagent,wen2024autodroid}. GUI observation races~\cite{qian2026rebinding,jiang2026atomicity} and filesystem check/use races~\cite{bishop1996races} share the action boundary that snapshot validation cannot close, a requirement that a position paper calls decision coherence~\cite{jiang2026contextlake}.
