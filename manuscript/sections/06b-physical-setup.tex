\paragraph{Physical phone.}\label{sec:phys-setup} Physical runs use \PhysDevice phones (\PhysAndroid, \PhysFingerprint, \PhysRooted) rented on AWS Device Farm. A run lasts at most 150 minutes on a freshly reset phone, so each run installs the apps, grants permissions and writes synthetic fixtures; the Python drivers run over adb on the Device Farm Linux host. Runs landed on \PhysInstances units, so every trial records its unit; the cached-app freezer was already off on \PhysFreezerOffUnits units of known state, so each run turns it on first. The phones stay on the charger, so Doze is forced through \texttt{dumpsys} and we measure neither battery drain nor unplugged use.
