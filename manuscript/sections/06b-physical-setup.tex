\paragraph{Physical phone.}\label{sec:phys-setup} Physical runs use one \PhysDevice (\PhysAndroid, build \PhysFingerprint, \PhysRooted) rented on AWS Device Farm. A run lasts at most 150 minutes on a freshly reset phone, so each run installs the apps, grants permissions and writes synthetic fixtures; the Python drivers run over adb on the Device Farm Linux host. Runs may land on different units of the model, so every trial records its unit (distinct units: \PhysInstances). The phone stays on the charger: Doze is forced with \texttt{dumpsys battery unplug} and \texttt{deviceidle force-idle deep}, and we measure neither battery drain nor unplugged use. Without root, the drivers use \texttt{run-as}, the cgroup files and \texttt{dumpsys activity} for app files, kills and frozen state.
