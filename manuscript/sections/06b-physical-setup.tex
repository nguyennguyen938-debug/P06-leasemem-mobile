\paragraph{Physical phone.}\label{sec:phys-setup} Physical runs use \PhysDevice phones (\PhysAndroid, builds \PhysFingerprint, \PhysRooted) rented on AWS Device Farm\ifPhysSamsung, and Galaxy~S25 phones (\PhysSamsungModel, same Android release, build \PhysSamsungBuild) for the callback and race tests only\fi. A run lasts at most 150 minutes on a freshly reset phone, so each run installs the apps, grants permissions and writes synthetic fixtures; the Python drivers run over adb on the Device Farm Linux host. Every trial records its unit. Pixel~8 runs landed on \PhysUnitsTrials units; the cached-app freezer was off by default on \PhysFreezerOffTrialUnits of them (\PhysFreezerOffUnits of the \PhysUnitsFreezerKnown units whose state is known, counting probe-only units), so each run turns it on first. Where a test ran on several Pixel~8 units, per-unit results agreed; the callback, race and host tests each ran on one unit (Table~\ref{tab:phys-units}).\ifPhysSamsung{} The Galaxy~S25 trials come from \PhysSamsungUnits units. Its freezer was off by default on \PhysSamsungFreezerOffUnits units, and even with it on a cached client never froze (\PhysSamsungFrozen attempts), so its callback test omits the frozen deployment.\fi The phones stay on the charger, so Doze is forced through \texttt{dumpsys}.
