\paragraph{Physical phone.}\label{sec:phys-setup} Physical runs use \PhysDevice phones (\PhysAndroid, builds \PhysFingerprint, \PhysRooted) rented on AWS Device Farm\ifPhysSamsung, Galaxy~S25 phones (\PhysSamsungModel, same Android release, build \PhysSamsungBuild)\fi\ifPhysNine{} and \PhysNineModel phones (\PhysNineAndroid, build \PhysNineBuild)\fi. Each run, at most 150 minutes on a freshly reset phone, installs the apps, grants permissions and writes synthetic fixtures through Python drivers over adb; every trial records its unit. The cached-app freezer was off by default on \PhysFreezerOffTrialUnits Pixel~8 and \PhysSamsungFreezerOffTrialUnits Galaxy~S25 units behind the reported trials, so each run turns it on first.
