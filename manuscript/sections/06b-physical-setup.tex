\paragraph{Physical phone.}\label{sec:phys-setup} Physical runs use one \PhysDevice (\PhysAndroid, build \PhysFingerprint, root: \PhysRooted). It is a personal phone, so every experiment runs in a separate user, \texttt{P06 Test}, with synthetic data only; every user-scoped command targets that user, and the drivers refuse other users. Device-wide settings (Doze, battery state, freezer debounce) are recorded and restored after each step. Without root, the drivers use \texttt{run-as}, the cgroup files and \texttt{dumpsys activity} for app files, kills and frozen state; unplugged runs (24-hour state log, battery) use wireless debugging. SMS (its store is shared across users), clock rollback, Contacts reset and the persistent system app keep emulator results. The call log and the action-boundary experiment, whose effect is a call-log row, run only if calls are off for the test user, keeping its call log apart from the owner's; otherwise they keep emulator results too. \texttt{PHYS-PROTOCOL.md} in the artifact lists the host setup, commands and exclusions.
