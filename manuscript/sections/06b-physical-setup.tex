\paragraph{Physical phone.}\label{sec:phys-setup} The physical runs use one \PhysDevice (\PhysAndroid, build \PhysFingerprint, root: \PhysRooted). It is a personal phone, so every experiment runs in a separate Android user, \texttt{P06 Test}, holding only synthetic data; all adb commands target that user, and the drivers refuse any other. Device-wide settings changed for a run, such as the freezer debounce, are recorded and restored. Without root, the drivers use \texttt{run-as} to read app files and kill the client, and read frozen state from the cgroup or \texttt{dumpsys activity}. The 24-hour state log and the battery runs use wireless debugging, because natural Doze and battery drain need an unplugged phone. Clock rollback, Contacts reset and the persistent system app are not run on this phone and keep emulator results only. \texttt{PHYS-PROTOCOL.md} in the artifact lists the Windows host setup, every command and every exclusion.
