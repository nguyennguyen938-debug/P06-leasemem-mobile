\paragraph{Physical phone.}\label{sec:phys-setup} Physical runs use \PhysDevice phones (\PhysAndroid, builds \PhysFingerprint, \PhysRooted) rented on AWS Device Farm\ifPhysSamsung, Galaxy~S25 phones (\PhysSamsungModel, same Android release, build \PhysSamsungBuild)\fi\ifPhysNine, \PhysNineModel phones (\PhysNineAndroid, build \PhysNineBuild)\fi{} and \PhysEightAModel phones (\PhysEightAAndroid, build \PhysEightABuild) from a second account. Each run, at most 150 minutes on a freshly reset phone, installs the apps, grants permissions and writes synthetic fixtures over adb; every trial records its unit. The cached-app freezer was off as provisioned on \PhysFreezerOffTrialUnits Pixel~8 and \PhysSamsungFreezerOffTrialUnits Galaxy~S25 units behind the reported trials, so each run turns it on first. Every unit with the freezer off whose setting we read had a global \texttt{cached\_apps\_freezer=disabled} setting (\PhysFreezerCfgOffDisabled); who set it is unknown, so it says nothing about users' phones.
