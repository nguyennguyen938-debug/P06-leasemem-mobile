\paragraph{Derived outputs.} Current inputs do not make a generated output current. Reusing an output for equal inputs is safe only if the input keys capture every dependency and the output asserts nothing beyond them; a draft with current structured fields can still carry stale text from context outside the keys. The task oracle (\S\ref{sec:agent-tasks}) checks structured inputs, task identity and nonempty text, not whether the text reflects the new facts.

\paragraph{External validity.} Emulators on one host, with scripted mutations, supply the source map, policy campaigns and counterexamples. Physical results come from one phone model (\PhysDevice) rented on Device Farm and describe that model, not every vendor or release; where phone and emulators differ, we report both, and experiments not run on the phone keep emulator results (\S\ref{sec:phys-setup}). Even units of that model differ (the cached-app freezer was already off on \PhysFreezerOffUnits), so a client should not assume its deployment's lifecycle behavior. The rented phones stay on the charger and their Doze is forced, so we have measured neither how often gaps occur in real use nor battery drain on a physical phone. The summed-call model and measured draft tasks have different workloads. Unsupported stock contracts remain disabled, and selected query inspection is not population coverage. Ambiguous temporal overlaps are not counted as successes.

\paragraph{Platform opportunities.} Useful APIs would return values and sequence counters atomically, expose reset-safe epochs and complete changes including deletions, and support conditional effects. Public counters alone would not repair an inconsistent observation. Such APIs could make reuse worthwhile for expensive sources, but the present measurements do not establish a general performance advantage.
