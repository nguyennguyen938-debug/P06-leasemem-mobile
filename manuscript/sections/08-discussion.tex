\paragraph{Derived outputs.} Current inputs do not make a generated output current. Reusing an output for equal inputs is safe only if the input keys capture every dependency and the output asserts nothing beyond them; a draft with current structured fields can still carry stale text from context outside the keys. The task oracle (\S\ref{sec:agent-tasks}) checks structured inputs, task identity and nonempty text, not whether the text reflects the new facts.

\paragraph{External validity.} Emulators on one host, with scripted mutations, supply the source map, policy campaigns and counterexamples. Physical results come from one phone (\PhysDevice) and describe that device and build, not every vendor or release; where phone and emulators differ, we report both. The phone is a personal device, so every run uses a separate Android user with synthetic data, and experiments not run there keep emulator results only (\S\ref{sec:phys-setup}). The 24-hour state log follows a scripted schedule inside that test user, not a person's real use: it shows which gaps such a day produces, not how often they occur for real users. The summed-call model and measured draft tasks have different workloads. Unsupported stock contracts remain disabled, and selected query inspection is not population coverage. Ambiguous temporal overlaps are not counted as successes.

\paragraph{Platform opportunities.} Useful APIs would return values and sequence counters atomically, expose reset-safe epochs and complete changes including deletions, and support conditional effects. Public counters alone would not repair an inconsistent observation. Such APIs could make reuse worthwhile for expensive sources, but the present measurements do not establish a general performance advantage.
