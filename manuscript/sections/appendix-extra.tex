\section{Additional Results}
\label{app:extra}

\paragraph{Short-hold condition.} A first set of runs held each gap only 0 to 4\,s, so every change was younger than the 10\,s deferral at the early decision. Its \ETwoRone valid background trials appear as the last block of Table~\ref{tab:trial}. Event-driven policies missed \RoneEarlyEvK of \RoneEarlyChanged changed uses early, and \stamp \RoneEarlyLmK. The Tether-style policy (event-driven propagation, no durable versions) refines which facts an event invalidates. It therefore never misses fewer changes than event-only: \AllTeK vs.\ \AllEvK at the late decision of the background runs.

\paragraph{Hold-distribution sensitivity.} For one quiescent write, an unfrozen process, a deterministic callback delay $D$ and a decision at $H+2$ seconds, silence persists with probability $P(H<D-2)$. With $D=10$ and $H\sim U[0,h]$, this is $\min(1,8/h)$: \HoldSensFour, \HoldSensTen, \HoldSensThirty and \HoldSensSixty for $h=4,10,30,60$ seconds. At +14 seconds it is zero under these assumptions. This analytic sensitivity explains why the chosen hold distribution changes event-only rates; it excludes freezing, lost coverage, setup callbacks and concurrent writes, and is not a field-frequency estimate.

\paragraph{Resumed LLM tasks: protocol.} A shared prefix records the inputs and the model-generated action, injects the gap and updates Contacts, MediaStore and Calendar with the schedule probability. Each model and schedule has 24 trials rotating three tasks; pairing stays within a model, and both models run at temperature zero with a fixed seed. An execution is timed from input acquisition through model invocation or reuse to the readback of the draft file, which the host writes with \texttt{adb push}, so it is not an on-device app effect; setup, gap and cached-output creation are untimed. The oracle checks exact structured inputs, task identity and a nonempty draft against provider reads after the arm. These are constrained draft tasks, not AndroidWorld completion or a quality evaluation, and no message is sent. Because no write overlaps an arm, the experiment cannot detect a stale action. Evidence minus refresh was \TaskPairEvidAllQwen for Qwen and \TaskPairEvidAllLlama for Llama over all trials (Table~\ref{tab:agent-tasks}).
