# Revision protocol and interfaces

`LmApp.observe` retains historical fields solely for explicitly named historical baselines and adds `certificates_v4`. A certificate binds `fact`, `source`, `value`, `support`, `read_start_ns`, `read_end_ns`, `contract`, schema 4, verdict and reason. Its query is the fixed fact catalogue in `LmApp.read`; final records also name that query definition. No stock adapter currently establishes the full strict contract. Reading returns a value with UNKNOWN certification; callers requiring a snapshot must decline or use an appropriate cooperative provider. Historical/weak ablations are not the default strict path.

`Revision.bracket` implements the cooperative reference adapter. It reads complete evidence before the query and after all support/delta snapshots. Up to three attempts are allowed. Every failed attempt is retained and discarded from certification. An accepted result contains the exact inner snapshot and its monotonic timestamp. Provider `call` operations (`snapshot`, `put`, `delete`, `reset`, `restore`) are serialized SQLite transactions. The epoch changes on managed reset/restore; every ordinary mutation increments the revision. Reset is not classified as a proven value change. Values are compared after successful same-epoch validation. The provider is non-exported, runs in `:reference`, and is only a controlled cooperative reference. Arbitrary file rollback or writers bypassing it invalidate the contract.

The loopback helper listens on device 127.0.0.1:8766. A test host uses adb forwarding and one newline-delimited JSON request/reply per connection. `op=batch` selects `mode=refresh|validate|memo|relay`. All arms use the same transport and privileges; each mode has its own cache. Input memoization's new measurement is the base-input-read stage, not LLM inference. The relay never clears dirty flags during a batch, avoiding lost invalidations; resetcache is a harness operation at a new trial's setup. Dirty flags remain conservative within a trial. The helper is debug instrumentation and does not provide production authentication.

`op=reference` runs named deterministic interleavings against a separate provider process. `op=stock_evidence` records richer observed metadata with `certified=false`. Historical race injection reads facts using the archived logic, changes the provider via the mutator, and assigns the final watermark separately. This recomposes the vulnerable schedule on real providers; it is not claimed to be an uninstrumented natural race occurrence.

A validation timestamp is not the later action time. Independent per-source snapshots do not constitute a simultaneous multi-source snapshot. Later truth reads during ongoing writes are ambiguous evidence about an earlier read. The independent Python oracle checks interval ordering and state/version consistency from logs, without invoking the Java decision implementation.
